# love-h5 · UI 设计规范（Macaron OS）

> 配套高保真设计稿：[design/index.html](../design/index.html)——浏览器直接打开即可，顶部工具栏可**切换 8 套主题**、勾选**「显示安全区」**可视化检查每屏的上下安全边距。
> 设计稿示例机型：iPhone 15 Pro（灵动岛，安全区上 59pt / 下 34pt）。

---

## 1. 设计基调

**关键词：温柔 · 软糖质感 · 玻璃拟态点缀 · 大数字仪式感。**

- 按 **App 标准设计**，不是网页观感：集成式状态栏、毛玻璃导航栏/TabBar、底部半屏 Sheet、长按菜单、按压缩放反馈、页面转场动画
- 8 套马卡龙主题贯穿全局，主题切换 `<html data-theme>` 一步全站生效
- 延续铁律：**UI 一律不用 emoji 当图标**（Iconify · lucide 线性图标）；心情 emoji 属产品数据不受限

## 3. App 化体验清单（H5 按 App 做的实现要点）

| # | 项 | 实现 |
|---|---|---|
| 1 | 视口 | `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no">` |
| 2 | 状态栏着色 | `<meta name="theme-color">` 随主题切换由 JS 同步（PWA 下状态栏/地址栏跟着变色） |
| 3 | 高度单位 | 全屏容器用 `100dvh`（避免移动端地址栏收放跳动） |
| 4 | 禁橡皮筋 | `html,body{overscroll-behavior:none}`；滚动区单独 `overflow-y:auto` + `-webkit-overflow-scrolling:touch` |
| 5 | 触控体验 | `-webkit-tap-highlight-color:transparent`；`touch-action:manipulation`（灭双击缩放延迟）；可点目标 ≥44×44px |
| 6 | 按压反馈 | 全局 `.pressable:active{transform:scale(.96);transition:120ms}` |
| 7 | 页面转场 | vue-router + 转场类：二级页右滑入 300ms、返回左滑出 |
| 8 | 震动反馈 | 关键操作 `navigator.vibrate(10)`（Android；iOS 网页不支持自动降级） |
| 9 | 长按菜单 | 气泡/卡片长按 500ms 弹出仿 iOS 菜单（聊天：复制/引用/收藏/撤回/删除） |
| 10 | 骨架屏 | 列表首屏用主题色渐变 shimmer 骨架 |
| 11 | 下拉刷新 | 自绘（主题色小圆环），不用浏览器默认 |
| 12 | PWA | manifest + 图标 + standalone；添加到主屏后获得全屏无浏览器框的真 App 观感 |
| 13 | 桌面适配 | ≥560px 视口时限宽 480px 居中，两侧主题色渐变氛围背景（电脑自测双开就是两个"手机"） |

## 4. 安全区规范（重点，所有机型必须不破版）

### 4.1 原则

1. **内容永不进入安全区，背景永远延伸进安全区**（沉浸式：页面渐变背景铺满全屏，导航/TabBar 用毛玻璃垫在安全区内侧）
2. 一律用 `env(safe-area-inset-*)` 动态取值，**禁止写死机型数值**；下表仅作测试机型参考
3. `viewport-fit=cover` 是前提，没它 env 永远返回 0

| 机型 | 上（状态栏/刘海） | 下（Home 条） | 说明 |
|---|---|---|---|
| iPhone SE / 8 等非全面屏 | 20pt（PWA 下） | 0 | 浏览器内上边由地址栏占位 |
| iPhone X~13 / 14 | 44~47pt | 34pt | 刘海机型 |
| iPhone 14 Pro~16（灵动岛） | 59pt | 34pt | 设计稿示例机型 |
| Android 全面屏 | 24~48pt 不等 | 24~48pt 不等 | 各 ROM 差异大，全靠 env 兜底 |
| 桌面浏览器 | 0 | 0 | 走 480px 居中布局 |

> 浏览器行为须知：**普通浏览器里顶部 inset≈0**（地址栏占位）、**底部 inset 正常返回**（页面延伸到 Home 条下方）；**添加到主屏（PWA standalone）后顶部 inset 才生效**。所以顶部垫 env 后浏览器里自然为 0、PWA 里自动避开刘海——一份代码两种形态都对。

### 4.2 CSS 实现（生产代码直接抄）

```css
/* ── 安全区变量：全站唯一取值口 ── */
:root {
  --sa-top:    env(safe-area-inset-top, 0px);
  --sa-bottom: env(safe-area-inset-bottom, 0px);
  --sa-left:   env(safe-area-inset-left, 0px);
  --sa-right:  env(safe-area-inset-right, 0px);
}
/* 老 iOS 11.2~11.3 回退（constant 语法） */
@supports (padding: constant(safe-area-inset-bottom)) {
  :root {
    --sa-top:    constant(safe-area-inset-top, 0px);
    --sa-bottom: constant(safe-area-inset-bottom, 0px);
    --sa-left:   constant(safe-area-inset-left, 0px);
    --sa-right:  constant(safe-area-inset-right, 0px);
  }
}

/* ── 各组件的消耗方式 ── */
.page        { min-height:100dvh; padding-left:var(--sa-left); padding-right:var(--sa-right); }
.nav         { padding-top:var(--sa-top); }                                /* 导航栏把状态栏区垫出来 */
.tabbar      { padding-bottom:calc(8px + var(--sa-bottom)); }              /* 底部 Tab 垫 Home 条 */
.sheet       { padding-bottom:calc(20px + var(--sa-bottom)); }             /* 半屏弹层同理 */
.fab         { bottom:calc(92px + var(--sa-bottom)); }                     /* 悬浮按钮避开 TabBar+Home 条 */
.chat-input  { padding-bottom:calc(8px + var(--sa-bottom)); }              /* 全屏聊天输入栏 */
.list-plain  { padding-bottom:calc(24px + var(--sa-bottom)); }             /* 无 TabBar 的二级页列表尾部 */
```

### 4.3 视觉验收

设计稿 `design/index.html` 勾选「显示安全区」→ 每台"手机"上会以**粉色斜纹 + 虚线**标出上/下安全区，逐屏检查：
- 顶部：状态栏文字、导航栏内容不得压进斜纹区
- 底部：TabBar 图标、Sheet 的按钮、FAB、聊天输入栏不得压进斜纹区
- 背景渐变必须铺进斜纹区（不允许出现白边）

## 7. 图标体系

- 库：**Iconify · lucide**（线性、2px 描边、圆角端点），Vue 里 `@iconify/vue`
- UI 任何位置**禁用 emoji 充当图标**（铁律，从源项目 CLAUDE.md 延续）；用户产生的心情 emoji、聊天内容不受限
- 色彩：图标继承 `currentColor`，跟随所在容器主题
